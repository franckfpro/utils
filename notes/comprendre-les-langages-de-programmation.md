# Comprendre les langages de programmation

## Référence

- Transcript: "The Programming Language Guide — Not A Top 10 List" (vidéo, présentation sur diapositives).
- Public visé: les débutants comme les personnes apprenant un deuxième ou troisième langage.

## Idée centrale

Choisir un langage demande moins de listes de classement que de compréhension des catégories fondamentales qui les distinguent: niveau d'abstraction, mode d'exécution, typage.

## Points clés

- Annonce du programme: panorama des langages modernes, leurs usages, leur fonctionnement, avec les axes d'analyse suivants: bas niveau contre haut niveau; compilé contre interprété; typage statique contre typage dynamique.
- Notion de bas niveau et haut niveau:
  - Le "niveau" mesure la proximité entre le code écrit et ce que la machine comprend.
  - L'ordinateur ne comprend directement ni JavaScript, ni C#, ni Java: le code doit être converti en instructions comprises par le processeur.
  - Le niveau traduit donc la proximité avec le matériel et le degré d'abstraction entre les deux.
- Base de la hiérarchie: le matériel, au niveau le plus bas; au-dessus, le langage machine (code machine), code de niveau le plus bas, fait d'instructions strictement numériques en binaire (zéros et uns) qui pilotent le processeur; représentation plus lisible en hexadécimal (extrait interrompu à ce point).
- Éléments d'avis éparse dans les fragments du transcript:
  - Le couple .NET et C#: un excellent choix de pile technologique pour de nombreux usages; Visual Studio sert à créer des applications C#, et C# est l'un des langages avec lequel cet environnement a été construit, avec VB.
  - Motif de choix de Node.js pour le back end: disposer du même langage côté front end et côté back end.
